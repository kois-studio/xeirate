# Work queue

[`TODO.md`](TODO.md) is the tracked source of truth for unfinished work. Work items use the shared standards statuses: Proposed, Ready, Active, Blocked, and Deferred.

High-impact product, privacy, architecture, data, and deployment changes remain Proposed or Blocked until the required human decision is recorded. Completed work is represented by implementation evidence and updated current-state documentation rather than kept as stale active items.
